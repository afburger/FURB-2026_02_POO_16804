# ProjetoPratico

Projeto prático da disciplina de Programação Orientada a Objetos (POO).
Reúne os exemplos apresentados em aula e as resoluções dos exercícios, organizados por unidade.

## Estrutura

O código é dividido em dois pacotes principais:

- `exemplos`: códigos demonstrados durante as aulas.
- `exercicios`: resoluções dos exercícios propostos.

Dentro de cada um há um pacote por unidade:

```
src/
├── exemplos/
│   ├── unidade01/
│   ├── unidade02/
│   └── ...
└── exercicios/
    ├── unidade01/
    ├── unidade02/
    └── ...
```

## Convenções

- Um pacote por unidade dentro de `exemplos` e `exercicios` (`unidade01`, `unidade02`, ...).
- Cada classe em seu próprio arquivo, com nome descritivo.
- Cada unidade corresponde ao conteúdo registrado no material de aula (ver `Unidade01.md` e demais).
